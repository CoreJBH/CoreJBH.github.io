POCKETCORE

A full node, not a promise: the chain is checked on the phone that holds it.

POCKETCORE
Bitcoin Core 32.1 · Android arm64

An unmodified bitcoind — Bitcoin Core 32.1, cross-compiled for aarch64-linux-android — runs as a child process of a foreground service on your phone and is driven over loopback JSON-RPC. Every block on screen has had its proof of work, Merkle root, scripts and ECDSA/Schnorr signatures checked by Core's own code on your own CPU. Nothing is re-implemented in Kotlin. Nothing is delegated to a server.

03 / PRINCIPLES

What the work is held to

01

Verify, don't trust

No number on a screen is taken from a peer, an API or a vendor. It is computed by code that ships with the app and can be rebuilt from source.

02

Nothing leaves the device

No analytics, no crash reporting, no advertising IDs, no third-party SDKs. The only network traffic is the one the protocol needs.

03

Keys are never in the middle

A node stays a node (ENABLE_WALLET=OFF); a wallet keeps its keys on the phone. Nothing is custodial.

04

Limits are written down

Build records, hashes and known gaps are published with each release. A tool that hides its edges cannot be audited.

04 / ABOUT

The code is the credential

CoreJBH is an independent engineering label: one developer, no company behind it, no funding round, no team page and no marketing department. The projects are built to be read — single-file apps, unmodified upstream trees, unit tests and a build record that names every hash it ships.

There is no account to create and nothing to subscribe to. If you want to know what a tool does, open the source, rebuild it, and compare the hash of your build with the one in the release.
